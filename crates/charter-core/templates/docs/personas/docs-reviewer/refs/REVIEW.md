# Reviewing a Docs only change

What `docs-reviewer` checks in every change. Edit it to match how this project works: it is
yours, and a chat reads the copy here.

- [ ] Is it true? Check each claim about behaviour against the thing it describes.
- [ ] Does the page say who it is for and what they can do after reading it?
- [ ] Does every link and every cross-reference resolve?
- [ ] Do code samples run as written, with nothing left for the reader to guess?
- [ ] Is a term used the way the rest of the docs use it?
- [ ] Is it as short as it can be and still be clear?
