headline: A piece's worktree gets charter's layer, so a session started where `charter wt add` says to start one has the plugin, the persona agents and the plane's ask/deny rules
adopt: workspace reinit --all
---

`charter wt add <repo> <piece>` cuts a worktree at `workspaces/<ws>/.worktrees/<repo>/<piece>`
and prints `enter: cd <that path> && claude`. That directory is a git root of its own, so
Claude Code reads `.claude/settings.json` from it and nowhere else, and its search for
`.claude/agents/` and `.claude/skills/` stops there. Charter wrote its layer into the clone
beside it and never into the worktree. A session in the worktree had no charter plugin, no
`$CHARTER_HARNESS`, none of the plane's persona agents or skills, and none of the plane's `ask`
or `deny` rules. `charter workspace reinit` said there was nothing to do, and `doctor`'s
`workspace layer` row was green.

Now a worktree gets the same layer a clone gets, hidden in the clone's `.git/info/exclude`:

- `charter wt add` writes it before it prints the `enter:` line, and says so.
- A launch and `charter workspace reinit` write it into every worktree git lists for a
  workspace's clones. That includes one made with plain git at the layout's path, one an older
  charter cut, and one under a root moved by `[plane] worktrees` or `$CHARTER_WORKTREES`.
- `doctor`'s `workspace layer` row lists a worktree's files, as
  `api/.worktrees/svc/p1/.claude/settings.json (missing)` or by absolute path under a moved
  root. A chat started in a worktree is told which of the plane's ask/deny rules are not in
  force there.
- `charter workspace remove` takes charter's files out of the workspace's worktrees first.
  That matters under a moved root, where the worktree directory outlives the workspace.

A worktree whose path leads out of the directory it belongs under is named and gets nothing
written into it. For `workspaces/`, that is a `.worktrees` symlinked elsewhere. For a moved root,
it is a `<root>/<ws>` symlinked out of that root. `wt add` warns about it, `reinit` reports it
`blocked`, and `doctor` reports it `foreign`.

`charter doctor` lists any worktree still missing the layer, and `charter workspace reinit
--all` writes it there.
