headline: `charter persona default <name>` names the file it could not write and the system's error, instead of asking whether this is a control plane
---

When `charter.toml` could not be written, for example because it was read-only,
`charter persona default <name>` answered `could not write …/charter.toml — is this a
control plane?`. The plane was a control plane, so that sent you to check the wrong thing,
and the system's own error was not shown.

Now it prints `could not declare the default persona: could not update <path> (<the
system's error>).` and exits 1, the same sentence `--clear` prints for the same failure.
When there is no `charter.toml` at all it says `there is no <path> to declare it in.`
