headline: A profile whose config folder lacks charter's plugin is wired by the launch itself, instead of refused with the command to run
---

`charter claude-alt` on a folder charter had never wired used to stop at a refusal and name
the fix: `charter harness install claude-alt`. Now the launch runs that install itself — the
same `claude plugin marketplace add` and `claude plugin install charter@charter` — says so in
one line, asks the harness again, and starts the chat only once the folder answers *wired*:

    ✓ charter: wired 'claude-alt' — installed charter@charter into /Users/you/.claude-alt

An opencode profile gets its shim the same way. The profile selector draws such a row as one
that starts, `not wired yet — Enter installs charter@charter into …`, rather than refused; a
`+`, a workspace tab, `charter reopen` and a handoff install at their own first probe and
report it where they report everything else. `charter doctor` still only probes; its hint
says the next launch installs it.

There is no question in between. The one that stands for your approval of a profile —
`run this? [y/N]`, shown once for a new or changed command — has already been answered by the
time charter looks at the folder, and the plugin is what makes that chat a guarded one.
Nothing installs as a side effect of an unrelated command: `charter workspace list` still
installs nothing, and the plugin goes only into the folder the profile names.

What still refuses, each with its fix in the sentence: a folder charter could not ask (a probe
that timed out or would not parse is not installed over), a profile you have not approved or
one in a `charter.local.toml` git would commit, an install that failed (the refusal names what
`claude` said), a plugin that is installed and disabled, and **Codex** — its hooks are trusted
only inside a Codex session, so charter writes its own line into `$CODEX_HOME/config.toml` and
the launch stops with Codex's steps, as before.

Measured on claude 2.1.272: the first launch pays the marketplace clone — 7 to 18 seconds
across two runs, paced by the network, no login needed — and the second pays nothing. Two
launches of one unwired profile at once are serialised — the second waits, then says it
found the plugin already in place.

Nothing to adopt.
