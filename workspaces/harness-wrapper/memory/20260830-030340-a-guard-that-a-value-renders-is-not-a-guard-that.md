_2026-08-30 03:03 · persistent_

A guard that a value RENDERS is not a guard that it FITS where it is sent. charter's release guard ran the same `charter news --for` that announce pipes into `gh release create`, so 'the guard passed' and 'the notes render' could not disagree — and that was sound, and still let a 333,917-character body reach an API that refuses over 125,000, after the irreversible PyPI upload (#665, PR #672). When a value crosses into a sized sink, assert the size at the producer, not the shape.
