# A child charter a test starts (tmux panel, detached frame-gather, 'chart

_2026-09-10 14:27 · persistent_

A child charter a test starts (tmux panel, detached frame-gather, 'charter hook sessionstart' run as a subprocess) is invisible to tests/_planeguard BackgroundCharterChild, which only watches the test process. Since #938 the frame gather and SessionStart call update.maybe_spawn, so such a child on a fresh test plane forks a real _version-check (PyPI GET): one full run forked 18. Fix per fixture with tests._isolation.no_update_check_in(plane) (plants the cooldown lock); where the plane must have no .charter/, set the child's https_proxy to http://127.0.0.1:9. To count them, temporarily log from update.maybe_spawn when 'tests._planeguard' is not in sys.modules.
