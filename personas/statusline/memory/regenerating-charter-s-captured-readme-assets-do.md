Regenerating charter's captured README assets (docs/assets/): the pipeline is documented in docs/assets/README.md and MUST be followed — never hand-edit an SVG (hand-positioned per-glyph x coordinates). Three traps learned on 2026-08-21 doing the 0.47.1 refresh: (1) LIVE-STATE SURFACES NEED A FIXTURE. The 'inflight' badge draws only while a dispatch is genuinely out, so demo-plane.sh had to be taught to write inflight records the way inflight.start does (back-dated so it reads an age, not the presumed-dead '?'), or the capture comes back half-stale on the exact feature being captured. The script already fabricates inventory/repos.json, pieces/seen/*.json and the forge-state cache for the same reason. Verify which file actually carries a version banner: only statusline.svg does.
