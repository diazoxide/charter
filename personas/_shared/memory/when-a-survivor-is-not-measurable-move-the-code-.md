WHEN A SURVIVOR IS NOT MEASURABLE, MOVE THE CODE — DO NOT LOWER THE STANDARD. On #923/#926 a mutation landed in charter/config.py, where any line has the whole suite as its covering set (329 modules): it timed out after 900s, twice, so the sweep could not decide. The agent did not merge on a hand measurement and did not declare it unkillable. It moved the path helper out of config.derive into workspace._tab_order_file(), a 21-module covering set — which was independently the better home on charters own precedent, since frame.state._root, frame.gather._cache_file and persona.ephemeral_dir all spell their own state path in the module that owns it. The sweep then measured it, and the branch verdict went from "no verdict: 1 not measured" to "no survivors". Note the cost it paid deliberately: an attribute name pins a filename literal for free and a function does not, so it added a test pinning the literal, because the news entry prints that path to operators. General rule: an unmeasurable survivor is usually telling you the code is in the wrong place — a line nothing can isolate is a line every test depends on.
