# charter save commits whatever is pending in the plane's tree, not only m

_2026-09-13 00:46 · persistent_

charter save commits whatever is pending in the plane's tree, not only memories - check the directory breakdown, never the file count. Measured 2026-09-12: a save reported 169 files, which read as a large but ordinary batch of persona memories. Listing the commit by directory showed 104 shared memories, 31 steward, 20 forge, 9 statusline, 2 release, two dispatch logs - and uv.lock, a repo file that had NEVER existed in this repository, created by some agent's local uv run on the machine and never gitignored. So a project file reached main through the plane's save mechanism, with no PR and nobody choosing it; it was removed in a follow-up commit that recorded how it arrived. Two things follow: a save's count is not a description, and one command over the commit's own file list is the whole check. Also worth knowing: charter save rebases onto a moved remote and retries, so the commit SHA it first prints can no longer exist by the time it finishes - read the SHA off the remote, not off the save's output.
