A FIXTURE THAT AGREES WITH THE MACHINE'S DEFAULT TESTS NOTHING. Measured on #505/#588 (2026-08-27): a hand-check fixture did a UTF-8 round-trip, which passes on any UTF-8 machine — so 'encoding=' could be deleted from BOTH branches and nothing went red. Same shape as a test inheriting the ambient umask, one variable over. Fixed by using UTF-16, which no platform defaults to. Generalise: for any fixture whose correctness depends on an ambient setting (locale, umask, $COLUMNS, tty-ness, timezone, filesystem case-sensitivity), pick a value the machine would NEVER choose by default — otherwise the test agrees with the environment instead of with the code. Sibling techniques from the same PR: (a) when the sweep flags a mutation PLATFORM-unreachable, check whether the test can MAKE the failure happen rather than waiting for a platform that produces it — the #505 case makes fchmod fail, so the except clause is entered everywhere; (b) 'each half is caught' is exactly the claim second-order testing exists to disprove, so re-run green-together pairs after pinning individually rather than assuming.
