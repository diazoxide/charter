# AN ISSUE CAN BE STALE ON ARRIVAL — DATE-CHECK ITS CLAIMS AGAINST git log

_2026-09-02 22:50 · persistent_

AN ISSUE CAN BE STALE ON ARRIVAL — DATE-CHECK ITS CLAIMS AGAINST git log BEFORE ACTING ON THEM. #828 said to DELETE a guard as dead code ('a survivor the suite cannot redden'). It was already pinned: the case ACaptureCharterCannotEncodeStillLands merged in #820 at 17:44, and #828 was filed at 18:51 the SAME DAY — the issue was written against a tree an hour old. Deleting on its word would have cut a documented guard. Rule: when an issue asserts 'nothing tests this' or 'this is unreachable', check the filing time against 'git log --since' for the files it names, and grep for a test before believing it. Related: a survivor is not automatically a missing test [[a-survivor-can-be-unobservable-rather-than-unrea]].
