Escaping text at one surface proves nothing about the others; ask where else the same bytes reach a terminal. Measured on charter PR 983 (2026-09-12): a mutation sweep flagged one line that escapes brief text into a duplicate-notice message, and asking the class question instead of fixing the line found three more surfaces carrying the same attacker-influenced bytes raw - a refusal the operator is TOLD TO PASTE INTO A TERMINAL, which routes the whole brief through shlex.quote (single quotes escape nothing, so ESC, backspace and bidi pass through, and a brief beginning with a carriage return and a success message repaints charter's own refusal as success); the todo listing and its search path; and the committed todo file with its index row. Two further renderers in the frame could not be driven in the reviewer's harness and were reported as unmeasured rather than assumed safe. The repo already had a test forbidding exactly this for workspace names, on a surface a thousand times smaller. A renderer is where untrusted text must be escaped, never on the way into storage, which would corrupt the file a person reads.
