# A workspace clone is not privately yours: a coordinator or sibling agent

_2026-08-22 11:31 · persistent_

A workspace clone is not privately yours: a coordinator or sibling agent may run git in the SAME working tree mid-task. An unexplained branch/HEAD change there is far more likely a sibling than a charter defect — establish that before suspecting charter, and never file a defect naming a mechanism you could not reproduce (a ghost issue costs more than the bug). Corrective: assert the branch and HEAD identical before AND after any long verification run
