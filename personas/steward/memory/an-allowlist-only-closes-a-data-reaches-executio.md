An allowlist only closes a data-reaches-execution hole when the field names a CLOSED grammar charter owns (a news check: names a charter subcommand — #319). For an OPEN grammar (an MCP command: any binary + any args), an allowlist on the first token is defeated by the args and refusing the real launchers (npx/uvx/docker) breaks every working plane. The axis with an answer there is operator consent, not enumeration — #330/PR 346.
