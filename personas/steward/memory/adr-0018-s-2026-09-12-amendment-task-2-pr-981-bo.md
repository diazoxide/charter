ADR 0018's 2026-09-12 amendment (Task 2, PR #981) bounded what charter writes in a chat pane before the exec at 'two sentences, and charter wrote both … no escape sequences of charter's own, no panel, no layout, and never a third thing later'. The profile selector is a whole overlay.Surface in the alternate screen with the pane in raw mode, so that bound did NOT cover it and had to be amended again in the PR that first drew it (ruling 44). The distinguishing question is unchanged — has a harness ever run in this pane, and is charter's process still the one in it. Lesson: a bound written as a COUNT of what charter happened to write that week is a bound the next feature breaks; the question is what the pane is FOR before the exec.
