### Security

- **A command that asks for your consent is refused when spelt so that nothing would ask.** A
  report filed with `--yes` and a todo promoted to a forge wait for your yes through rules spelt
  with the bare `charter` name. The guard now refuses either command when it is spelt so those
  rules don't match: through a path to the binary, in another case, behind a prefix or a
  wrapper, quoted, in a subshell, or inside a string or heredoc a shell runs. The refusal names
  the spelling that asks. The persona tool gate now reads a program's name in any case, as the
  other guards already did (#1279).
