### Added

- **Answer a task's question from its row and from its tab's menu.** While a task waits on a
  question to the chat that dispatched it, its row menu in the Chats list, its own tab's menu
  and the palette have an _Answer_ row for it, and its line in its session tab's menu has an
  Answer button at its end. Each opens the same form as the Activity tab, in a dialog: the
  question, a box, _Send_ and _Cancel_. A press outside the dialog does not close it, so what
  you typed is not lost; if the question is answered elsewhere while it is open, the dialog
  says so and keeps your text (#1551).

### Changed

- **A task's line in a tab's menu shows its buttons to the keyboard too**, and a screen reader
  hears what the task is doing when it asks for the line's description (#1551).
