### Added

- **The Inbox lists updates after what waits on you.** A task that finished or failed, a doctor
  finding, a chat that came back, a sandbox block that asks nothing, a dispatch refused while
  you were away and a Smart close that stopped each become an update, newest first, with
  Dismiss, and Go to chat where it is about one. Mark all read and Dismiss all act on updates
  only; nothing that waits on you is ever answered in bulk. Updates are kept for a day on this
  machine, in purlis's data home and never in a project, so a relaunch keeps them (#1693).

### Changed

- **A task that failed is an update, not something waiting on you**: the ✋'s number no longer
  counts a chat that is listed only because a task of its failed (#1693).
- **A dispatch refused while you were away is answered in the Inbox**, with its three answers
  (Never for this pair, Allow from now on, Dismiss), and the away summary's part for it opens the
  Inbox. It and a Smart close that stopped are no longer rows in the title bar's list (#1693).
