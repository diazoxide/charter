### Added

- **Some refusals inside dialogs now offer a way out** (NO-8, #1233).
  - When git would carry your local settings file, the Start a chat dialog offers Add the ignore
    line, the fix the doctor's row applies, and then reads its profiles again.
  - The dialog's list of refused profiles links to Settings › Harness & profiles.
  - When the repo picker says a forge's CLI is not logged in, it offers that CLI's login. The
    login is typed into a shell tab at the project root, and you run it yourself.
  - The Extensions dialog's line about an unreadable extension record has Read again.
