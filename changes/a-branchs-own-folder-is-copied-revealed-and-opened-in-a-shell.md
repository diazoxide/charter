### Added

- **A branch's own folder can be copied, revealed and opened in a shell.** A branch's row in the
  explorer, and its *Files* row, have *Copy absolute path*, *Reveal* and *Open a shell tab here*,
  as a folder inside it has; the palette lists them for each branch of the focused workspace.
  A branch folder that is itself a link is refused, never followed (#1143).
