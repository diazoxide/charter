### Security

- **An unattended chat dispatches only under a grant that already stands.** A chat whose
  harness runs with its permission prompts off has nobody to answer a dispatch grant's Notice,
  so it is never shown one. Its dispatch to another persona starts only when a grant covers the
  pair for you on this machine or for everyone in this project; a grant made for one chat never
  counts for it. Without one the dispatch is refused in a sentence that names the missing pair
  and says how a person grants it, nothing is kept waiting, and no grant can be made from the
  ask. An unattended chat that was started with no sandbox dispatches to no other persona at
  all, since nothing would keep it from changing who it may dispatch to. The persona chat an
  unattended chat starts takes none of this: it starts as the project and this machine declare
  it, with its own persona's hosts and vault, no opt-out and no permission mode of the asking
  chat's, and it waits in its own tab, shown as needing you, when it asks. A persona chat is
  not started on the asking chat's profile where that profile's own command switches the
  prompts off (#1446).
