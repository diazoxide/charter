### Added

- **Show what changed in a file.** In a branch's file tab, a file the branch changed has *Show
  what changed* beside it in the preview. It opens a tab with the file against the branch it
  was cut from, committed or not, its changed lines marked as `git diff` marks them. A file
  the branch did not change has no such button, and a binary file, one past 2 MiB or one
  charter cannot read is said in a sentence rather than drawn as an empty diff (FM-11, #1114).
