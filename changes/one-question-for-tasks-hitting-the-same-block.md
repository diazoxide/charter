### Added

- **A task's question names its whole path, and one question covers tasks hitting the same
  block.** What a task asks of you is on its session's tab, named by the path purlis recorded
  when it started the task, each name quoted: `“deep” (a task of “steward 4” › “talk”)`.
  When several tasks of one session are blocked on the same host, or on writing the same
  folder, one Notice asks once ("3 tasks want to reach registry.npmjs.org"), lists each task, and its one answer applies to
  each of them: **Allow for these tasks** gives each task its own grant, never the session
  that asked them, **Always allow…** keeps one grant for every chat here, and **Keep blocked**
  answers each. Every task allowed restarts on its conversation once its turn ends. A task
  blocked after the question was shown joins it visibly, and a press just after a question
  appears or changes does nothing (#1508).

### Security

- **A sandbox permission given to a session does not reach its tasks**, and one given to a task
  reaches neither its session nor its siblings. One answer to several tasks names the block
  shown for each task, and is refused whole unless purlis holds each task on exactly that block
  now and its own record puts each below that session (#1508).
