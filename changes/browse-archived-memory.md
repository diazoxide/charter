### Added

- **Browse and restore archived memory in the window.** Each memory list — a workspace's Memory
  section, a persona's tab, the shared list — has an archive button beside its `+`, and the palette
  has *Archived memory · <name>*. It opens the store's archive in a tab of its own: what Delete
  moved out, by title and stamp, each readable but not editable, with Restore memory to put it back
  under its name with its index line (KN-4, #716).
