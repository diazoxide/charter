### Added

- **A chat that did not start has Retry now and Forget this chat….** Retry now starts the chat
  again, the way a launch does, and its tab opens. If it still cannot start, the line stays and
  says why. Forget this chat… asks first, then drops the chat for good. Until you choose, the
  chat is kept, so a folder that moved never deletes it (NO-3, #1230).
- **Start fresh, for a chat the project's instructions changed under.** The mark on its tab is
  now a button, and the palette and the tab's menu have a *Start chat … fresh* row. After a
  question, the chat starts again on the project as it is now, as a new conversation under the
  same name (NO-3, #1230).
