### Added

- **Locate… a moved project from Settings too.** Settings › You › This machine offers Locate…
  beside Forget for a recent project that has moved or gone, as the window's and the opener's
  notices do: pick the folder it is in now, and the entry is re-pointed there (#1291).

### Fixed

- **A link to a setting focuses it in its own Settings tab.** With two Settings tabs of the same
  level split side by side, a link that names a setting could put the focus in the other tab
  (#1292).
