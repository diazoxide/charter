### Added

- **Messages that name a setting open Settings at its group.** A doctor row whose fix is a
  setting, such as a `[[forge]]` block that does not resolve or a `[plane]` key purlis does not
  read, has a Fix it in Settings button. It opens Settings at that project's level with the
  group shown, such as Forges, Saving or Harness & profiles. A text size or editor in the layout
  file that purlis could not use gets the same button in the alerts drawer, which opens the
  Text or Editor group. A Settings tab already open for that level is brought forward rather
  than opened again. Each level now shows the group you last looked at there until the window
  closes (SE-22, #1172).
