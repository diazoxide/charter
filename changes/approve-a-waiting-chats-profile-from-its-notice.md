### Added

- **Approve a waiting chat's profile from its Notice.** When a chat did not start because its
  profile's command is new or changed, its Notice offers *Review and approve…*. It opens the
  new-chat picker's own approval sentence with the exact command line, and the file is checked
  against that line again before anything is recorded. Approving starts nothing: *Retry now*
  runs the whole start again (#1246).
