### Changed

- **Rename workspace, Start a chat, the first run and Updates look like Settings.** Their boxes,
  choices and ticks are drawn as Settings draws a setting: a name, the control, and a line on
  what it means. In Settings, _Your editor_ now moves to the editor a single arrow key reaches.
  Updates holds the channel you pick until you press **Use this channel**, so moving through the
  channels with the arrow keys no longer moves the machine to one (DS-3d, #1176).
