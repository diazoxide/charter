### Added

- **Project settings in the Settings tab.** Its level switcher now offers Project beside You,
  with the project's settings in eight groups: General, Saving, Harness & profiles, Sandbox,
  Forges, Extensions, Appearance and Plugins; a group with nothing to set is left out. Each
  change is written to its file as you make it — a pick at once, a typed value when you leave
  the field — keeping every other key and comment, and the last change has an Undo. A value
  charter refuses is said beside its setting, which keeps showing what is in the file. Keys
  the old page reached only as raw TOML have a control here: the sandbox, the Assisted-by
  trailer, the icon theme and the environment passed to chats. Project settings stays where it
  was for now (SE-17, #1167).
