### Added

- **A project that has moved or gone offers Locate… and Forget.** The window's note about a
  project it could not reopen, and the opener's line about a recent project that is gone, now
  have two buttons. Forget takes the project off this machine, so it no longer comes back at
  every launch. Locate… asks for the folder it is in now, checks there is a project there, and
  opens it in the project's old place, with its pins and tab. The project is asked about again,
  as at a first open. Neither happens on its own, because a disk that is unplugged may come back
  (NO-5, #1237).
