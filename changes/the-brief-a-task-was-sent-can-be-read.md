### Added

- **The brief a task was sent can be read.** **Brief** is on a task's row menu in the Chats
  list, on a finished task's row, and on the pane's top line while a tab shows a task. Each
  opens the same read-only panel: the brief as it was sent, who sent it (the chat that asked,
  or you), when, to which persona and where the task works. The brief is shown as text and is
  never rendered: no link in it is live and no image is loaded. A long brief scrolls in its
  box and is not cut, and **Copy** gives it exactly as it was sent. Where a brief holds
  characters that draw as nothing or change how the text around them reads, each is written
  out as its code and the panel says so. The brief is read from the task's dispatch record,
  so a finished task has it too, and nothing new is stored (#1494).
