### Added

- **A file or folder row has a menu, and nothing on it changes a file.** Right-click a file or
  folder in the explorer's tree or in a file tab's tree, or press Shift+F10 on it, to copy its
  path relative to the branch or its absolute path, reveal it in Finder, Files or File Explorer,
  open a file in your editor, or open a shell tab in a folder. charter offers no create, rename,
  move or delete, so it never races an agent writing the same branch. A link is not followed:
  its row copies only its relative path (FM-10, #1113).
