### Changed

- **The sidebar remembers each project as you left it.** Explorer's folded sections, the repos you
  folded and the folders you opened come back for each project after a relaunch, and so does the
  Chats view's This tab / Workspace / All pick, which moves from the window's storage into
  `layout.json` (#1686, #1696). Existing layout files load as they are.
