### Added

- **A branch's files in the explorer.** Each branch in the left sidebar, and each repo for its
  own folder, has a *Files* row that opens folder by folder into its files, read only as each
  folder is opened. Folders come first, in the order you read names. A file opens in its file
  tab, by click or Enter, and the arrows, Home and End move through the tree. What git ignores
  is hidden until *Show ignored files*, then drawn dimmed and never opened; a file charter will
  not open, such as a link out of the branch, says why beside it. A file an agent adds or
  removes in an open folder shows up without a refresh. A folder of thousands of files shows
  its first 5,000 and counts the rest (FM-1, #1104).

### Changed

- **The light editor opens the files of a repo's own folder too**, with the same checks as a
  branch's (#948), and when it will not open a file it now says so in terms of the branch's
  folder (FM-1, #1104).
